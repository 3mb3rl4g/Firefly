## 一、FPS 理解的总体框架

### 1.1 一句话概括

FPS 的胜负 = **硬件下限** × **系统流畅度** × **基本功** × **信息与心态**。

前两项决定你**能不能打出该有的水平**，后两项决定你**能打到多高**。绝大多数人卡在低分段，不是天赋问题，而是这四项里有一项长期漏风。

### 1.2 两个方向

| 方向         | 内容                                     | 作用                       |
| ------------ | ---------------------------------------- | -------------------------- |
| **硬件（外设）** | 显示器、鼠标、键盘、耳机、鼠标垫         | 决定操作精度的**物理上限** |
| **软件（设置）** | 系统精简、电源计划、显卡驱动   | 决定帧数与延迟的**稳定性** |
| **基本功**   | 准星摆放、预瞄、移动、急停、听声辨位     | 决定**对枪胜率**           |
| **意识与复盘** | 地图理解、信息判断、心态、Demo 复盘      | 决定**上分高度**        |

### 1.3 常见误区

| 误区                     | 实际情况                                       |
| ------------------------ | ---------------------------------------------- |
| 打得菜就换更贵的鼠标     | 传感器性能早已溢出，**模具合手**才是关键       |
| 一味追求 4K 高画质       | FPS 优先帧数，**1080p 高刷**才是主流选择       |
| 灵敏度越低越准           | 太低会被身法拖死，要**匹配你的鼠标垫与手臂空间** |
| 用机械键盘更有"手感"     | 磁轴的**快速触发与急停**是实打实的性能优势     |
| 只练枪不练走位           | 多数对枪在你开枪前，**位置就已经决定胜负**     |

## 二、硬件：外设

> 对其它类型游戏来说，外设影响有限；但对 FPS 来说，外设的重要性不亚于弓箭对于弓箭手。**没有合适的外设，天生就低人一等。**

### 2.1 重要程度排序

| 优先级 | 外设     | 核心理由                             |
| ------ | -------- | ------------------------------------ |
| ★★★★★  | 显示器   | 决定你能看到多少、反应有多快         |
| ★★★★★  | 鼠标     | 唯一的瞄准输入设备，模具决定手感上限 |
| ★★★★   | 键盘     | 磁轴决定急停与身法响应速度           |
| ★★★     | 耳机     | 决定信息获取（脚步、换弹、道具）     |
| ★★      | 鼠标垫   | 影响一致性，够用即可                 |

### 2.2 显示器

#### 先说结论（暴论）

**尺寸无脑选 24 寸，没有例外。**

超过 24 寸，你就无法靠眼球一次扫完整块屏幕，必须转头或转眼球，这就是**多余动作**。在 FPS 里，多余动作 = 慢一步 = 输。

#### 三个关键参数

| 参数       | 说明                                       | FPS 建议                     |
| ---------- | ------------------------------------------ | ---------------------------- |
| **尺寸**   | 屏幕对角线长度                             | **24 寸（24.5 寸为赛事标准）** |
| **刷新率** | 每秒刷新次数，单位 Hz，144Hz 即每秒刷 144 次 | **≥144Hz，能上 240Hz 更好**  |
| **分辨率** | 屏幕上像素点数量，同尺寸下越多越清晰       | **1080p**；高配且在意画质才 2K，**不要更高** |

#### 面板类型

| 面板          | 优点                     | 缺点                   | 结论           |
| ------------- | ------------------------ | ---------------------- | -------------- |
| **VA**        | 对比度高、便宜           | 天生拖影/鬼影          | **直接淘汰**   |
| **IPS**       | 色彩与速度均衡、可视角度好 | 漏光、对比度一般       | **首选性价比** |
| **TN**        | 响应最快、便宜           | 色彩差、可视角度差     | **可选**       |
| **OLED（常被叫 LED）** | 色彩好、响应极快、不漏光 | 可能烧屏、价格高       | **有钱就上**   |

#### 选购公式

```plain
24 寸 + 1080p + ≥144Hz + IPS 或 TN（预算充足上 OLED）
```

还可以额外关注：

- **响应时间**：GTG 1ms 级别即可，别只看营销数字
- **拖影/过冲**：看实测评测，OD（Overdrive）档位是否可调
- **支架**：必须能升降调高度，让屏幕中心与视线齐平
- **接口**：DP 优先，HDMI 高刷可能受限

### 2.3 鼠标

#### 现状判断

以前鼠标市场被**罗技**和**雷蛇**统治，卓威占一部分。随着国产鼠标崛起、罗技摆烂，目前**最高的山是雷蛇**。

但真正的问题是：**这个时代传感器性能早就超出人类极限了**。随便一个主流鼠标的性能都是溢出的，所以选购时**只需要关注模具是否合手**。

而模具这块，国产鼠标非常灵活，致敬了无数经典模具，再配上极致性价比——**国产鼠标早就是答案了**。

#### 关注点排序

| 关注点        | 说明                                                         |
| ------------- | ------------------------------------------------------------ |
| **模具/握法** | 趴握、抓握、指握，手长手宽决定选大中小号                     |
| **重量**      | 主流 40–60g，越轻越省力，但太轻需要适应                      |
| **无线延迟**  | 主流 2.4G 已接近有线，优先选带独立接收器的                   |
| **回报率**    | 1000Hz 够用，2000/4000Hz 需高刷屏与强 CPU 才吃得住，8000hz根本没用 |
| **微动/滚轮** | 手感与寿命，可换微动是加分项                                 |
| **LOD**       | 静默高度，越低越不影响抬鼠                                   |

#### 品牌建议

**ATK、雷柏、迈从、万灵、scyrox、兰族**——通过不断"无理由退货"试出适合自己的模具即可。

### 2.4 键盘

#### 结论

键盘市场依旧被国产薄纱，目前**已经是磁轴的天下**。选任意一款国产大牌的**磁轴入门款**就 OK，同样是数值超模爆炸。

推荐看 **ATK、迈从**，性价比高。

#### 为什么是磁轴

> 磁轴不能帮你从青铜到王者，但可以帮你从铂金到钻石。

| 对比项       | 机械轴             | 磁轴（霍尔效应）              |
| ------------ | ------------------ | ----------------------------- |
| **触发方式** | 物理触点，固定触发点 | 磁场感应，**触发点可调**    |
| **快速触发** | 无                 | **RT（Rapid Trigger）**，抬手即复位 |
| **急停速度** | 受键程限制         | **0.1mm 级触发**，急停更快    |
| **回报率**   | 1000Hz 常见        | 1000–8000Hz                   |
| **寿命**     | 触点磨损           | 无触点，寿命更长              |

同样的价格，为什么不选性能更强的磁轴，而去选过时的机械轴？

#### 关键设置

```plain
触发点：0.1–0.5mm（WASD 可更低）
RT 快速触发：开启，灵敏度 0.1mm
回报率：1000Hz 起步，配置够就 4000/8000Hz
```

### 2.5 耳机

虽说是因人而异，但经过亲身体会，**耳机无脑选"飓风"就完事了**（HyperX Cloud 系列）。国产耳机目前还不够强。

关注点：

| 关注点       | 说明                                     |
| ------------ | ---------------------------------------- |
| **声场与定位** | 能否清晰分辨脚步方向与距离             |
| **佩戴舒适** | 长时间佩戴不夹头、不闷耳                 |
| **麦克风**   | 队友能听清即可，不必追求直播级           |
| **虚拟 7.1** | 多数游戏内建 HRTF 更好，虚拟环绕不要开！ |

### 2.6 鼠标垫

有影响，但影响不大。**随便选一款入门基础口粮垫就可以了**，其它的其实没有吹得那么神。

可以看看 **fastpad、垃圾桶外设** 等。

| 类型       | 特点                     | 适合             |
| ---------- | ------------------------ | ---------------- |
| **布垫**   | 通用、耐用、性价比高     | 绝大多数人       |
| **涂层垫** | 更滑、更快，但寿命短     | 追求速度感       |
| **玻璃/树脂** | 极快、极稳，磨损脚贴  | 高阶玩家         |

尺寸建议 **450×400mm 起步**，保证大范围拉枪不脱垫。

## 三、软件：系统与驱动调优

> 软件方面就是调整好自己的系统设置。Windows 默认带了很多玩家用不到的设置和服务，可以通过工具禁用掉，让电脑更流畅、更高帧。

### 3.1 影响最大的三项

| 项目           | 作用                             | 优先级 |
| -------------- | -------------------------------- | ------ |
| **电源计划**   | 防止 CPU 降频，稳定帧数          | ★★★★★  |
| **显卡驱动**   | 降低延迟、关闭垂直同步与省电     | ★★★★★  |
| **内存 XMP/EXPO** | 一键解锁内存标称频率，提升 1% Low | ★★★★★  |

### 3.2 系统精简清单

| 项目                    | 操作                                        |
| ----------------------- | ------------------------------------------- |
| **鼠标加速**            | 关闭"提高指针精确度"，注册表 `MouseSpeed=0` |
| **Game Bar / Xbox DVR** | 卸载                                        |
| **全屏优化**            | 对游戏 exe 关闭"全屏优化"                   |
| **VBS / 内存完整性**    | 关闭（会掉帧），确认无安全软件依赖          |
| **后台服务**            | 禁用 SysMain、Windows Search 等非必要服务   |
| **系统动画**            | 关闭窗口动画与透明效果                      |
| **Windows 更新**        | 打游戏时段暂停，避免后台占用                |

**命令行版（管理员 PowerShell）：**

```powershell
# 开启"卓越性能"电源计划
powercfg -duplicatescheme e9a42b02-d5df-448d-aa00-03f14749eb61

# 关闭鼠标加速
reg add "HKCU\Control Panel\Mouse" /v MouseSpeed /t REG_SZ /d 0 /f
reg add "HKCU\Control Panel\Mouse" /v MouseThreshold1 /t REG_SZ /d 0 /f
reg add "HKCU\Control Panel\Mouse" /v MouseThreshold2 /t REG_SZ /d 0 /f
```

### 3.3 显卡驱动设置

| 设置项             | NVIDIA 建议                     | AMD 建议                |
| ------------------ | ------------------------------- | ----------------------- |
| **垂直同步**       | 关闭                            | 关闭                    |
| **低延迟模式**     | 高（配合 Reflex）             | Anti-Lag 开启           |
| **电源管理模式**   | 最高性能优先                    | 最高性能                |
| **纹理过滤质量**   | 高性能                          | 性能                    |
| **三重缓冲**       | 关闭                            | 关闭                    |
| **G-Sync/FreeSync** | 高刷屏可开，配合帧数上限使用    | 同左                    |
| **着色器缓存**     | 开启（减少卡顿）                | 开启                    |

游戏内同时开启 **NVIDIA Reflex / AMD Anti-Lag**，可显著降低输入延迟。

### 3.4 内存 XMP / EXPO

进 BIOS 打开 **XMP（Intel）/ EXPO（AMD）**，让内存跑到标称频率（如 6000MHz）。这是**零成本提升 1% Low 帧**的操作，很多人装机后一直没开。

### 3.5 工具推荐

| 工具                | 用途                                   |
| ------------------- | -------------------------------------- |
| **Win11 轻松设置**  | 一键关闭遥测、动画、冗余服务           |
| **ZyperWin++**      | 系统精简与优化脚本集合                 |
| **DDU**             | 干净卸载显卡驱动后重装                 |
| **MSI Afterburner** | 监控帧数、帧生成时间、温度             |
| **CapFrameX**       | 记录帧时间曲线，排查卡顿               |

> 优化原则：**只做可回滚的改动**。改注册表前先导出备份，别用来路不明的"一键优化"。

## 四、基本功：FPS 的本质

### 4.1 核心概念：点小球

**FPS 游戏本质就是点小球：谁点得更快更准，谁就赢。其它一切，都是为了点得更快更准。**

### 4.2 动作拆解

```plain
发现目标 → 移动鼠标把准星移到目标上 → 点击开火 → 击碎目标
   （发现）        （瞄准）                （开火）
```

可以归为三步：**发现、瞄准、开火**。

人类反应时间约 **150–250ms**，而移动鼠标到目标还要额外时间。所以想赢，只有两条路：

1. **缩短每一步的时间**（硬件、灵敏度、训练）
2. **直接省掉某一步**（准星摆放 + 预瞄）

### 4.3 准星摆放

#### 目的

通过管理准星的位置，**把"发现"和"瞄准"合并成一步**，从而比对手更快开火。

#### 要求

> 全部时间都要注意自己的准星放在哪里。目标是：**对面只要出现，就一定在你的准星上，你只需要点一下鼠标就能击杀。**

#### 两条铁律

| 铁律             | 说明                                                     |
| ---------------- | -------------------------------------------------------- |
| **守头线**       | 准星永远保持在人物头部高度                                 |
| **守走向**       | 你要往哪走，准星就对着哪，让准星一直停在敌人可能出现的位置 |

两者一合并，就是**预瞄**。

### 4.4 头线

FPS 游戏的人物模型通常是同一套复制粘贴的，**人物高度完全一致**。再加上第一视角的近大远小透视，**所有人的头都在同一条水平线上**。

所以平时把准星放在这条线上，遇到人就直接是头部高度，省掉"往上抬枪"这一步。

实际应用：

- 贴墙走时，准星贴着墙角边缘的头线
- 过拐角时，准星提前放在拐角外侧的头线
- 上下坡、楼梯、箱子处要**重新校准高度**

### 4.5 预瞄的两种形态

| 类型           | 做法                                                     | 适用场景             |
| -------------- | -------------------------------------------------------- | -------------------- |
| **走位预瞄**   | 准星始终对着你前进方向、敌人可能出现的位置               | 全程通用             |
| **隔墙预瞄**   | 确定敌人位置或可能蹲伏点时，隔墙提前把准星移到位，走到位停下的瞬间准星正好在敌人头上 | CS 系列、架点、拉角 |

第二种是 CS 这类游戏的核心预瞄方式：**你不是看到人才瞄准，而是走到位时准星已经在人头上。**

### 4.6 移动的本质：近大远小

FPS 存在透视：**离掩体越近的人，看到的掩体越大、看到的其他画面越少；离掩体越远的人，看到的掩体越小、看到的画面越多。**

由此推出一个重要结论：

```plain
你贴着掩体蹲下 → 敌人从最远离掩体的角度一点点蹭过来
→ 敌人先看到你，而你的视角里还看不见他
```

这就是近大远小的实战体现：**贴墙的人视野更窄，拉远角的人先手。**

#### 移动原则

| 原则                   | 说明                                             |
| ---------------------- | ------------------------------------------------ |
| **走远角**             | 尽量从离敌人掩体最远的角度走，先看到对方         |
| **积极找掩体**         | 遭遇战第一时间能进掩体反击，而不是原地对枪       |
| **少走开阔地**         | 暴露面越大，被多个角度同时看到的概率越高         |
| **过点不停留**         | 危险路口一次过完，别在中间犹豫                   |

## 五、进阶补全

### 5.1 灵敏度与 eDPI

**eDPI = 鼠标 DPI × 游戏内灵敏度**，它才是跨设备可比的真实灵敏度。

| 项目           | 建议                                             |
| -------------- | ------------------------------------------------ |
| **DPI**        | 400 / 800 / 1600 都可以，选一个固定不动          |
| **eDPI 区间**  | CS 类常见 **600–1200**；Apex 类偏高              |
| **调整方法**   | 从高往低降，直到能稳定完成 180° 转身不抬鼠       |
| **一致性**     | 所有 FPS 尽量统一"厘米/360°"，形成肌肉记忆       |

### 5.2 急停与身法

| 技术             | 要点                                                     |
| ---------------- | -------------------------------------------------------- |
| **急停**         | 移动中反向按一下，停稳再开枪；磁轴 RT 让抬手即停 |
| **干拉** | 不Peek直接拉出，风险高，用于信息明确的地方破坏敌人的预瞄 |
| **peek** | 先露一小条身位骗枪，收集敌人位置信息，再决定是否完整拉出 |
| **蹲拉**         | 拉出瞬间下蹲，改变头部高度，打乱对方头线预瞄             |
| **跳拉**         | 利用跳跃改变弹道与命中判定，多用于进攻方                 |

### 5.3 听声辨位

| 声音类型     | 信息                         |
| ------------ | ---------------------------- |
| **脚步**     | 方向、距离、是否在跑         |
| **换弹**     | 对方弹匣空窗期，可强拉       |
| **道具**     | 烟雾/闪光/燃烧弹的使用意图   |
| **落地**     | 高处跳下的位置与时机         |

听声的前提是**耳机定位准确 + 游戏内 HRTF 设置正确**，别开虚拟 7.1 。

### 5.4 训练与复盘

| 环节       | 做法                                                     |
| ---------- | -------------------------------------------------------- |
| **热身**   | 10 分钟死斗或 Aim Lab / KovaaK's，唤醒手感               |
| **专项**   | 每天 15 分钟跟踪训练 + 15 分钟甩枪训练                   |
| **实战**   | 死斗练对枪，排位练决策，两者分开练                       |
| **复盘**   | 看自己的 Demo，只找**死亡原因**：位置？预瞄？信息？       |
| **记录**   | 记下每次死亡归类，一周统计一次，针对性改一个点           |

### 5.5 心态

- 连败三把就停，情绪上头时决策质量断崖式下降
- 只关注**自己能控制的事**：预瞄、走位、信息，而不是队友
- 上分是**长期均值**，单局胜负不说明任何问题
