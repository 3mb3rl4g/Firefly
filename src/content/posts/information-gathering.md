## 一、信息收集概述

### 1.1 什么是信息收集？

信息收集是渗透测试的**第一步**，目的是找到目标系统的**所有资产和攻击面**（可能的脆弱点）。

### 1.2 常见问题速查

| 问题                     | 答案要点                   |
| ------------------------ | -------------------------- |
| 拿到一个网站首先做什么？ | **信息收集**               |
| 信息收集分类？           | **主动**和**被动**         |
| 信息收集需要做些什么？   | **技术**和**社工**两个层面 |

### 1.3 任务类型

| 类型         | 目标                             |
| ------------ | -------------------------------- |
| **找漏洞型** | 给 IP/域名/页面，找漏洞          |
| **找资产型** | 给单位名称，找所有下属网站的漏洞 |

------

## 二、信息收集思路

### 2.1 针对具体某个网站或 IP

```plain
1. 翻页面，找可能的漏洞利用点
2. 找真实 IP（CDN 绕过）
3. 找网站源码
4. 扫敏感目录和文件（含后台）
5. 扫危险请求方式
6. 扫端口（+ 识别 OS）
7. 找旁站（C段、子域名）
8. 找供应链
9. 社工信息搜集（名字、联系方式等）
```

### 2.2 针对某个单位或集团

```plain
1. 搜集信息资产
   ├── 找子域名（扫描、爬虫、证书透明度）
   ├── 找真实 IP（CDN 绕过）
   ├── 扫端口服务
   ├── 扫危险请求方式
   ├── 扫敏感目录和文件
   └── 识别 CMS
2. 翻页面功能，尝试漏洞利用
3. 找供应链
4. 收集社工信息（whois、网页信息、源码信息）
```

### 2.3 攻击面分类

| 层面         | 内容                                                   |
| ------------ | ------------------------------------------------------ |
| **技术层面** | DNS、CDN、云服务器、OS、各类服务、代码的漏洞和不当配置 |
| **管理层面** | 人性弱点（社工）                                       |

## 三、技术信息收集

### 3.1 翻看网站页面 → 找漏洞利用点

#### 识别指纹（网站架构和源码名称）

| 指纹类型           | 内容                                                  |
| ------------------ | ----------------------------------------------------- |
| **操作系统**       | TTL 判断（128=Windows，64=Linux）、大小写判断、响应头 |
| **中间件**         | Apache、Nginx、IIS、Tomcat、WebLogic                  |
| **动态脚本解析器** | PHP、ASP.NET、JSP                                     |
| **数据库**         | MySQL、MSSQL、Oracle                                  |
| **CMS/框架**       | ThinkPHP、Shiro、FastJSON、Struts2                    |

#### 工具推荐

| 工具                 | 用途                       |
| -------------------- | -------------------------- |
| **Wappalyzer**       | 浏览器插件，识别网站技术栈 |
| **Nmap**             | 端口扫描、OS 识别          |
| **浏览器开发者工具** | 查看源码、网络请求         |
| **云悉指纹**         | https://www.yunsee.cn      |
| **微步社区**         | https://x.threatbook.cn    |
| **潮汐指纹**         | http://finger.tidesec.com  |

#### 已知漏洞搜索

| 平台       | URL                        |
| ---------- | -------------------------- |
| Seebug     | https://www.seebug.org     |
| Exploit-DB | https://www.exploit-db.com |

#### JS 源码中的敏感信息

- 产品 Banner 信息
- 网址资产
- 接口信息
- 个人信息、凭证
- 编码加密逆向信息

#### HTTP 响应头

可能泄露：服务器类型、框架版本、语言版本等。

### 3.3 绝对路径泄露

| 方法         | 说明                          |
| ------------ | ----------------------------- |
| 查看前端源码 | 报错信息可能包含路径          |
| 构造报错     | 故意填写不存在的路径或参数    |
| phpinfo      | 找 `DOCUMENT_ROOT` 或搜 `www` |

### 3.4 源码泄露恢复

| 场景         | 方法                                                |
| ------------ | --------------------------------------------------- |
| GitHub 泄露  | 搜索公司/CMS 信息                                   |
| .git 泄露    | 使用 GitHack 等工具                                 |
| .svn 泄露    | 使用 SVNHack 工具                                   |
| vim 缓存泄露 | 访问 `.index.php.swp`，使用 `vim -r index.php` 恢复 |

### 3.5 找真实 IP（CDN 绕过）

| 方法              | 说明                                                    |
| ----------------- | ------------------------------------------------------- |
| **子域名爆破**    | 不同子域名可能使用不同 IP                               |
| **邮件服务器**    | `mail.xxx.com` 与 `www.xxx.com` 同服时，查看邮件原文 IP |
| **Favicon Hash**  | 在 ZoomEye、FOFA、Shodan 中搜索 favicon 哈希            |
| **历史 DNS 记录** | https://viewdns.info、https://x.threatbook.cn           |
| **多地 Ping**     | http://ping.chinaz.com                                  |
| **换协议**        | 尝试 HTTP/HTTPS 不同协议                                |
| **证书透明度**    | https://crt.sh                                          |

**邮件原文查 IP：**

```plain
QQ邮箱 → 打开邮件 → 右侧三角 → 显示邮件原文 → 找 "X-Originating-IP"
```

### 3.7 端口扫描

#### 高风险端口（必须背诵）

| 端口                                           | 服务       | 说明                       |
| ---------------------------------------------- | ---------- | -------------------------- |
| 21                                             | FTP        | 文件传输，可能存在匿名访问 |
| 22                                             | SSH        | 远程管理，可爆破           |
| 23                                             | Telnet     | 明文远程命令，不安全       |
| 53                                             | DNS        | UDP 协议                   |
| 80, 443, 8080                                  | HTTP/HTTPS | Web 服务                   |
| 1433, 1434                                     | MSSQL      | SQL Server                 |
| 3306                                           | MySQL      | MySQL 数据库               |
| 3389                                           | RDP        | Windows 远程桌面           |
| 5432                                           | PostgreSQL | PostgreSQL 数据库          |
| 6379                                           | Redis      | Redis 数据库（未授权访问） |
| 7001                                           | WebLogic   | 管理界面                   |
| 1098, 1099, 4444, 4445, 8080, 8009, 8083, 8093 | JBoss      | JBoss 常用端口             |
| 9060, 9043, 9080, 9443                         | WebSphere  | 管理控制台                 |
| 4848, 3700                                     | GlassFish  | 管理端口、IIOP 端口        |

#### Nmap 常用命令

```bash
# 扫描网段存活主机
nmap -sn 192.168.68.0/24

# 识别操作系统
nmap -O 192.168.68.128

# 扫描端口（默认 1000 个）
nmap 192.168.68.128

# 扫描全端口
nmap -p 1-65535 192.168.68.128

# 推荐用法：操作系统 + 端口 + TCP半连接
nmap -A -T4 -sS 192.168.68.128

# 扫描网段特定端口
nmap -sS -p 80,443 192.168.68.0/24

# UDP 扫描 DNS
nmap -sU -p 53 192.168.68.0/24
```

#### Nmap 选项速查

| 选项  | 说明                   |
| ----- | ---------------------- |
| `-O`  | 操作系统版本           |
| `-F`  | 快速扫描               |
| `-A`  | 操作系统详情扫描       |
| `-sU` | UDP 扫描               |
| `-Pn` | 无需 ping 通直接扫端口 |
| `-sn` | ping 扫描在线情况      |
| `-iL` | 指定输入文件           |
| `-oN` | 指定输出文件           |
| `-sS` | 半连接扫描（提高速度） |
| `-p`  | 指定端口范围           |
| `-r`  | 随机扫描端口           |

#### Masscan（极速端口扫描）

```bash
# 特点：极速，结果可能不准确
masscan -p 1-65535 192.168.68.128
```

### 4.3 谷歌黑客（Google Hacking）

#### 基本语法

| 关键字      | 功能                        |
| ----------- | --------------------------- |
| `"xxx"`     | 双引号内内容不可拆分        |
| `site:`     | 指定域名                    |
| `inurl:`    | URL 存在关键字              |
| `intext:`   | 网页正文中的关键字          |
| `filetype:` | 指定文件类型                |
| `intitle:`  | 网页标题中的关键字          |
| `link:`     | 所有与该 URL 做了链接的 URL |
| `info:`     | 查找指定站点基本信息        |
| `-`         | 排除某个关键字              |
| `*`         | 通配符（代表多个字母）      |
| `+`         | 将忽略的字列入查询范围      |

#### 常用搜索

| 搜索意图       | Google 语法                                 |
| -------------- | ------------------------------------------- |
| SQL 注入页面   | `site:tw inurl:?id= filetype:php`           |
| 排除子域名     | `site:baidu.com -site:video.baidu.com`      |
| 后台登录       | `site:xxx.com intitle:"后台登陆"`           |
| 目录遍历       | `intext:"index of"`                         |
| 用户名密码文件 | `filetype:txt intext:username and password` |
| 敏感文件       | `site:tw filetype:inc intext:mysql_connect` |
| 后台管理       | `site:xxx.com 管理`                         |
| 邮箱信息       | `site:xxx.com intext:@xxx.com`              |
| 配置文件       | `site:xxx.com filetype:conf`                |
| 登录页面       | `site:xxx.com inurl:login`                  |
| MongoDB 状态   | `site:xxx.com intitle:mongod inurl:28017`   |
| phpinfo        | `site:xxx.com inurl:phpinfo.php`            |

## 📌 快速参考卡片

### 信息收集流程速查

```plain
1. 确定目标 → 域名/IP
2. 被动收集 → Whois、备案、谷歌黑客、子域名
3. 主动扫描 → 端口、目录、C段
4. 指纹识别 → CMS、框架、中间件
5. 找漏洞 → 搜索历史漏洞
6. 社工 → 邮箱、姓名、字典
```

### Nmap 命令速查

```bash
# 常用
nmap -sS -A -T4 目标IP
nmap -sn 192.168.1.0/24
nmap -p 1-65535 目标IP

# 选项记忆
-sS  半连接（快）
-A   全面扫描
-O   操作系统
-p   指定端口
-sn  只 ping
-Pn  跳过 ping
```

### 子域名查询速查

```bash
# OneForAll
python oneforall.py --target example.com run

# 域传送漏洞
nmap --script dns-zone-transfer --script-args dns-zone-transfer.domain=example.com -p 53 -Pn dns.example.com
```

# 常见备份文件名

index.php.bak
